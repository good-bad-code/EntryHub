# Entry-Hub 확장프로그램 공식 아이콘 가이드

크롬 웹스토어 등록 및 브라우저 툴바 노출을 위한 아이콘을 이 폴더에 배치해 주세요.

## 필요한 규격
1. `icon16.png` - 16x16 픽셀 (브라우저 탭 파비콘 및 확장프로그램 메뉴)
2. `icon48.png` - 48x48 픽셀 (크롬 확장프로그램 관리 페이지 `chrome://extensions`)
3. `icon128.png` - 128x128 픽셀 (크롬 웹스토어 설치 시 및 스토어 대표 아이콘)

## 권장 디자인
- 배경 투명 (PNG)
- Entry-Hub의 상징인 깔끔한 모던 블루 코드/블록 로고 형태 권장
